# v0.1 — IQR and HTTP API

Release identifiers: branch `release/v0.1`, annotated tag `v0.1.0`, Maven version `0.1.0`.
Both refs are created from completed, tested `master`. Resolve the immutable source with
`git rev-parse 'v0.1.0^{commit}'`; exact verified SHAs are recorded in the result report.

Scope: median-of-halves IQR, stateless Strategy/registry, strict JSON API, RFC 9457 errors,
dev-only opt-in Swagger/OpenAPI, local hooks, CI and strict generated JavaDoc.
This release does not contain Z-Score.

```json
{"algorithm":"IQR","data":[10,12,11,13,12,14,11,13,12,100]}
```

Default threshold 1.5 gives Q1=11, Q3=13, IQR=2 and bounds [8,16]. Anomalies are [100];
the remaining values retain input order and duplicates. `[5]` succeeds with SMALL_DATASET.
`[]` succeeds with NO_DATA, empty partitions and all five IQR statistics explicitly null.
Unknown algorithms and parameters are still validated on empty input.

Validation: **21 unit tests and 36 real HTTP integration tests**, no failures/errors/skips.
The release gate is full `./mvnw.cmd verify` (Unix: `./mvnw verify`), including
format/lint, independent core unit tests, real random-port HTTP integration tests and JavaDoc.
RED/GREEN evidence is in `docs/tdd/01-iqr-registry.md` and `02-http-api.md`.
Isolated hook fixtures test actual rejected commits and pushes without altering project files/index.

Limitations: synchronous in-memory requests, IEEE double precision, conservative 422 on unsafe
computed arithmetic, no configured input-size limit, no authentication or distributed components.
No benchmark claims are made. See [API](../api.md), [development](../development.md), and
[roadmap](../roadmap.md). The v0.1 tagged copy of these documents remains the authoritative v0.1 view.

Prompt AD-PRM-20261110-002; result AD-RES-20261110-002. This release note is preserved when v0.2 is added.

## v0.1.1 patch

Final v0.2 review found that direct Swagger WebJar resources bypassed the normal disabled UI
routes in v0.1.0. The API-only base configuration now disables general static mappings; dev
re-enables them only with SWAGGER_ENABLED=true. A real HTTP regression covers direct versioned
and versionless URLs. The normal API and explicit dev documentation remain verified.

The original annotated v0.1.0 tag is unchanged. The new annotated v0.1.1 tag and release/v0.1
head identify the corrected v0.1 line, with Maven/OpenAPI version 0.1.1. The fix was backported
on a patch branch from released master so no Z-Score implementation entered the IQR-only release.
Its clean RED/GREEN evidence is recorded in [the resource test log](../tdd/06-swagger-resources.md).
