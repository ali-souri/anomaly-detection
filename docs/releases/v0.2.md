# v0.2 — population Z-Score

Release identifiers: branch `release/v0.2`, annotated tag `v0.2.0`, Maven version `0.2.0`.
Both refs are created from completed, tested `master`. Resolve the source with
`git rev-parse 'v0.2.0^{commit}'`; the final result report records exact tested SHAs.
The v0.1 branch/tag and [v0.1 release note](v0.1.md) are preserved.
The v0.1.1 Swagger resource fix is included; the original v0.1.0 tag remains unchanged.

Adds `Z_SCORE` through the existing stateless strategy registry, without changing selection logic
or the IQR formula. Uses Welford mean/variance, **population divisor n**, then ordered classification.
Default threshold is 3.0. All finite non-negative overrides, including zero, are valid.

```json
{"algorithm":"Z_SCORE","threshold":1.5,"data":[2,4,4,4,5,5,7,9]}
```

Mean=5, standardDeviation=2; anomalies=[9]. At threshold 1.5 the value 2 lies exactly on the
score boundary and is normal. The original ten-value IQR example has no Z-Score anomaly at 3.0.
No threshold was manipulated to force agreement between algorithms.

Empty input returns NO_DATA with null mean/standardDeviation. Zero variance returns all normal
values with ZERO_VARIANCE; 1..3 values also keep SMALL_DATASET. The flat response has common fields
plus only mean/standardDeviation. OpenAPI uses oneOf and the explicit algorithm discriminator.

Validation: full `clean verify`, **39 unit tests and 47 real HTTP integration tests**, no
failures/errors/skips, formatting/lint, strict JavaDoc and class-diagram/document-link checks.
TDD evidence: [Z-Score](../tdd/04-z-score.md), [CI/review](../tdd/05-ci-review.md), and preserved
[v0.1 API](../tdd/02-http-api.md). Hook rejection evidence is [recorded separately](../tdd/03-hooks.md).
Remote CI is reported from actual GitHub API results, independently of these local checks.

Limits: double precision and conservative 422 for unsafe Welford intermediates, synchronous
in-memory processing, no size limit/authentication/distributed infrastructure. No benchmark or
v0.3 implementation is included. Benchmark this exact v0.2 before selecting any architecture
change; RabbitMQ, gRPC and per-algorithm services remain candidates.
